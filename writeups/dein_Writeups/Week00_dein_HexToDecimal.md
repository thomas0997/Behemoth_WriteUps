## Summary

This challenge focused on converting a hexadecimal value into its decimal equivalent. It also taught me the importance of using available tools to solve problems efficiently while still understanding the logic behind the process.

## Steps

1. The challenge asked: **"What is `0x3D` (base 16) in decimal (base 10)?"**

2. I learned that while understanding the step-by-step process of base conversion is important, using reliable tools can make solving these types of problems more efficient and save time.

3. I used the online tool **Binary Hex Converter**, which can convert hexadecimal values to decimal and vice versa.

4. I entered `3D` as the hexadecimal value into the converter, which gave me the decimal value **61**.

5. I also learned that using tools should not replace understanding the underlying process. In cybersecurity, knowing when and how to use reliable tools is an important practical skill, while understanding the logic behind the results allows me to verify that the tool is giving me the correct answer.

## Tools used

## Lesson learned

I learned that cybersecurity is not only about manually solving every problem from scratch. Understanding the fundamentals is important, but learning to use reliable tools can make the process more efficient and practical for real-world cybersecurity work.
