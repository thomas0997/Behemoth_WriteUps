## Summary
The challenge involved converting hexadecimal ASCII values into readable text. I used CyberChef's **From Hex** operation to decode the provided values and retrieve the flag.

## Steps
1. **Analyzed the input.** I noticed that each value started with `0x`, indicating hexadecimal notation.
2. **Decoded the values using CyberChef.** I used the **From Hex** operation to convert the hexadecimal values into readable ASCII characters.
3. **Retrieved the flag.** After decoding the input, I obtained the flag:

   `academy{45c11_n0_qu35710n5_1ll_t311_y3_n0_l135_e96c8ca8}`

## Tools Used
- **CyberChef:** Converted hexadecimal values into readable ASCII text using the From Hex operation.
