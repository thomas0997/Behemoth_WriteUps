## Steps

1. **Task 1: Introduction**
   - Read the introduction and learning objectives to understand what the room would cover.
   - Learned why understanding AI is becoming important in cybersecurity, especially as attackers and defenders begin using AI in their work.

2. **Task 2: Introducing TryHackMe's AI Agent Platform**
   - Explored the AI agent platform that would be used in the interactive challenges.
   - Learned that I could communicate with the agents using natural language and that the way I phrase my prompts can affect their responses.

3. **Task 3: What Is AI and Machine Learning?**
   - Studied the difference between artificial intelligence and machine learning.
   - Learned that AI is the broader field of making machines perform tasks that normally require human intelligence, while machine learning allows systems to learn patterns from data instead of relying entirely on explicitly programmed instructions.
   - Also learned about the machine learning lifecycle, from collecting and preparing data to training, evaluating, deploying, and monitoring a model.
   - Understood the meaning of **overfitting**, which happens when a model becomes too familiar with its training data and performs poorly on new data.

4. **Task 4: Machine Learning Algorithms**
   - Studied the four main types of machine learning algorithms and how each one learns.
   - Learned their differences:
     - **Supervised Learning:** Learns from labelled data that already contains the correct answers.
     - **Unsupervised Learning:** Finds patterns and relationships in unlabelled data.
     - **Semi-Supervised Learning:** Uses a small amount of labelled data together with a larger amount of unlabelled data.
     - **Reinforcement Learning:** Learns through actions and feedback in the form of rewards or penalties.
   - Learned that choosing the correct algorithm depends on the problem and the type of data available.

5. **Task 5: Neural Networks and Deep Learning**
   - Studied how neural networks process information through interconnected nodes arranged in layers.
   - Learned the purpose of each layer:
     - **Input Layer:** Receives the raw data.
     - **Hidden Layers:** Process the information and identify patterns.
     - **Output Layer:** Produces the final prediction or classification.
   - Also learned that the connections between nodes have weights that influence how information is processed.
   - Understood that deep learning uses neural networks with multiple layers to recognize more complex patterns in data.

6. **Task 6: Large Language Models**
   - Learned how Large Language Models (LLMs), such as ChatGPT, generate text by predicting the next token in a sequence.
   - Studied how these models are trained using large amounts of text and how their parameters are adjusted to improve their predictions.
   - Learned about **transformer neural networks**, which use attention mechanisms to determine which parts of the input are important in context.
   - Also learned about **Reinforcement Learning from Human Feedback (RLHF)**, a process that uses human feedback to help refine a model's responses.

7. **Task 7: Practical**
   - Reached the practical activity involving NEURON-1, an interactive neural network.
   - The activity applied the concepts of input layers, hidden layers, and output layers to a classification task.
   - Learned how raw input features can be processed into recognizable patterns before a final classification is produced.

8. **Task 8: Conclusion**
   - Reviewed the main concepts covered throughout the room.
   - Connected the relationship between AI, machine learning, deep learning, neural networks, and LLMs.
   - Recognized that understanding these fundamentals is an important starting point before studying AI-related security threats and defenses.

## Lesson Learned

I learned that AI is not just one technology but a broad field made up of different methods and systems that work together. Machine learning allows computers to learn patterns from data, neural networks help process more complex information, and LLMs use these techniques to generate human-like text. The interactive activities also helped make these concepts easier to understand instead of simply memorizing their definitions. As a cybersecurity student, I realized that understanding how AI works is important because the same technology can be used to improve security or help attackers develop more effective methods. Learning these fundamentals gives me a better starting point for exploring AI security in the future.
